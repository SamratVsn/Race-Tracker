# Race Tracker

> A simple coroutines demo app

A basic Android app that simulates a race between multiple runners using Kotlin Coroutines. Built as part of **Android Basics with Compose - Unit 5, Pathway 1** to learn coroutines and asynchronous programming.

---

## 🏃 About

**Race Tracker** is a learning project demonstrating how to use Kotlin Coroutines in Android. The app simulates concurrent tasks by running multiple "racers" at the same time and updating their progress on the screen.

This project is part of Google's **Android Basics with Compose** course:
- **Unit 5**: Connect to the internet
- **Pathway 1**: Introduction to coroutines

---

## 🎯 Learning Objectives

This project taught me:

- **Kotlin Coroutines**: Understanding asynchronous programming
- **Launch**: Starting multiple coroutines concurrently
- **Delay**: Simulating time-consuming operations
- **StateFlow**: Observing and updating UI state reactively
- **Background Tasks**: Running operations off the main thread

---

## ✨ Features

- **Race Simulation**: Multiple racers run simultaneously
- **Progress Tracking**: Visual progress bars for each racer
- **Real-time Updates**: UI updates as racers advance
- **Start/Pause Controls**: Simple race controls

## 🚀 Getting Started

### Prerequisites

- Android Studio (latest stable version)
- JDK 8 or higher

### Installation

1. **Clone the repository**:
```bash
   git clone https://github.com/SamratVsn/Race-Tracker.git
```

2. **Open in Android Studio**:
   - Launch Android Studio
   - Select "Open an Existing Project"
   - Navigate to the cloned directory

3. **Run the app**:
   - Connect an Android device or start an emulator
   - Click the "Run" button (▶️)
